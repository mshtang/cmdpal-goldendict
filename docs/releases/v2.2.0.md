## Development installer release

Download **CmdPal-GoldenDict-2.2.0-dev-Setup-x64.exe** below and double-click it to install for your Windows user account. Then run **Reload** in Command Palette and open **Local Dictionary Settings**.

**Windows 11, Command Palette, and Windows Developer Mode are required.** This unsigned development installer checks Developer Mode but does not enable it. Windows may show an unknown-publisher or SmartScreen prompt. This is not a production-signed release.

### Changes

- Bilingual English/Simplified Chinese EXE installation wizard.
- Automatic Windows package registration, repeat installation/upgrades, and uninstall.
- Keeps existing configuration and headword caches; leaves GoldenDict-ng and dictionary files unchanged.
- Handles installation paths with spaces, Unicode, ampersands, and square brackets.
- Blocks downgrades and prevents an old uninstaller from unregistering a different installed copy.
- Public repository documentation and repeatable GitHub Actions build/release workflows.
- Includes the bilingual compact settings UI, MDX suggestions, spelling corrections, and GoldenDict-ng forwarding from earlier versions.

### Notes

The EXE includes the .NET runtime. GoldenDict-ng and dictionary files are not included. Configure their paths in the extension after installing. For later updates, run the newer installer; no background updater or online lookup is added.

Verify the download using the accompanying `.sha256` file. Source code is available in this tag. Only Windows x64 is included in this release; ARM64 has not been validated on hardware.
