## Development installer 2.2.1

Download **CmdPal-GoldenDict-2.2.1-dev-Setup-x64.exe** and its `.sha256` file. Install for your Windows user account, then run **Reload** in Command Palette.

Windows 11 x64, Command Palette, GoldenDict-ng, and Windows Developer Mode are required. This unsigned development installer checks Developer Mode without changing it. The .NET runtime is included.

### Changes

- Full trimming reduces the locally measured installer from about 30 MiB to about 9 MiB while retaining self-contained operation and English/Chinese resources.
- Diagnostic CLI and PDB files are excluded from the user package; native runtime diagnostic libraries remain included.
- Updated Windows SDK managed projections and WinRT vtable generation eliminate trim warnings. Publishing fails on new trim warnings.
- Clean publication, runtime-mode checks, and size budgets prevent stale files and untrimmed payloads from entering the installer.
- CI tests the trimmed core and searches unique headwords in 25 synthetic MDX dictionaries through the actual extension's cross-process COM interfaces.
- Same-version development registrations can move from a source directory to the installation directory. Failed registration restores the previous development registration.
- Settings follow the Windows display language; the default All group combines enabled dictionaries while individual groups remain available.

Installation, reinstallation, COM activation, rollback, downgrade rejection, and uninstall have been tested locally. Configuration and existing caches are preserved. GoldenDict-ng and dictionaries are not included. Only x64 is distributed; ARM64 has build validation only. Real Palette UI acceptance remains a manual check. See `VALIDATION.md` for scope and measured limits.
